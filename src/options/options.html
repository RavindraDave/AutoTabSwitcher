Advanced Settings

Exciting features coming in future releases to give you even more control!

🚀 Roadmap - Features Coming Soon!

📌 Tab Filtering & Behavior

  • Skip Pinned Tabs - Exclude pinned tabs from auto-switching rotation to keep important tabs always accessible
  • URL Exclusion List - Specify URL patterns to skip (e.g., never switch away from video calls or important dashboards)
  • Skip Tabs by Domain - Exclude entire domains from rotation (supports wildcards)

🔀 Switching Order Options

  • Random Tab Order - Switch to tabs in random order instead of sequential for unpredictable monitoring
  • Reverse Direction - Switch backwards through tabs (right to left) instead of forward
  • Custom Tab Sequences - Define specific tab orders or priorities

⚙️ Enhanced Activity Control

  • Customizable Activity Triggers - Choose which actions trigger pause (tab switch, URL navigation, window focus, etc.)
  • Per-Tab Pause Duration - Different pause times based on tab type or URL
  • Smart Resume - Resume based on idle detection instead of fixed timers

📊 Advanced Features

  • Variable Delays per Tab - Spend more time on important tabs, less on others
  • Time-based Scheduling - Enable/disable auto-switching at specific times
  • Tab Groups Support - Only switch within specific tab groups
  • Keyboard Shortcuts - Quick toggle and control via hotkeys
  • Multi-Window Rotation - Cycle through windows in addition to tabs
