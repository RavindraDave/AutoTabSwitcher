# Auto Tab Switcher - Chrome Web Store Description

## Short Description (132 characters max)
Automatically cycle through browser tabs at configurable intervals. Global or per-window control with enhanced diagnostics.

## Detailed Description

Auto Tab Switcher is a powerful Chrome extension that automatically cycles through your open tabs at configurable intervals - perfect for monitoring dashboards, watching rotating content, or managing multiple information displays.

### ✨ **NEW in v2.0: Dual Operating Modes**

**🌐 Global Mode (Default)**
- Enable/disable all windows simultaneously
- All windows switch tabs together
- Perfect for multi-monitor setups
- Single-click control

**🪟 Window Mode (NEW!)**
- Control each window independently
- Each window has its own timer
- Enable only the windows you want
- Perfect for selective monitoring

### 🎯 **Key Features**

**Flexible Control**
- Choose between Global Mode (all windows) or Window Mode (per-window)
- Quick toggle from extension popup
- Context-aware buttons adapt to your current mode
- Configurable delays from 5 seconds to 1 hour

**Smart Behavior**
- Automatic pause on user activity (optional)
- Independent timers per window in Window Mode
- Resume automatically after activity period
- No interruptions during your work

**Visual Indicators**
- Color-coded badges: ON (green), PAUSED (orange), OFF (gray)
- Mode indicators in popup (Global/Window)
- Per-window status display
- Clear countdown timer

**Enhanced Diagnostics**
- 30-minute rolling log with mode context
- See which window triggered each event
- Mode indicators (🌐 Global / 🪟 Window) in logs
- Export logs as text or JSON
- Privacy-conscious logging

**Technical Excellence**
- Built with TypeScript for reliability
- Manifest V3 compliant
- Uses chrome.alarms API for efficiency
- Modular, maintainable architecture
- 100% backward compatible

### 📖 **How to Use**

**Quick Start - Global Mode:**
1. Click extension icon
2. Click "Enable All Windows"
3. All windows start switching tabs automatically!

**Quick Start - Window Mode:**
1. Go to Options → Select "Window Mode"
2. Open popup in desired window
3. Click "Enable This Window"
4. Repeat for other windows as needed

**Configure Settings:**
- Set tab switching interval (5-3600 seconds)
- Enable pause on activity
- Choose operating mode
- Customize behavior to your needs

### 🔄 **Upgrading from v1.x?**

No worries! Your settings are automatically migrated:
- "All Windows" → Global Mode (no change in behavior)
- "Selected Window" → Window Mode (now with multi-window support!)
- All settings preserved
- Zero manual configuration needed
